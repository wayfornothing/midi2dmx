1. Circuit d'entrée MIDI (Optocoupleur 6N138)

Légende des couleurs

Alimentation (+5V, +3.3V)
Masse (GND)
Signal MIDI
Signal vers ESP32
⚠️ Points importants :
  • La diode D1 protège contre l'inversion de polarité
  • R3 limite le courant dans la LED de l'optocoupleur
  • R2 assure le pull-up de la sortie du phototransistor
  • L'optocoupleur fournit une isolation galvanique complète
  • Pin 6 du 6N138 nécessite +5V, mais sortie compatible 3.3V

Table de connexions MIDI IN

Depuis Vers Type de signal
DIN5 Pin 5 D1 (Anode) MIDI Signal
D1 (Cathode) R3 MIDI Signal filtré
R3 6N138 Pin 1 Courant LED limité
DIN5 Pin 2 6N138 Pin 2 + GND Masse commune
6N138 Pin 6 +5V Alimentation optocoupleur
6N138 Pin 5 R2 puis +3.3V Pull-up sortie
6N138 Pin 5 ESP32 GPIO22 Signal MIDI décodé

2. Circuit de sortie DMX512 (Transceiver MAX485)

Légende des couleurs

Alimentation +5V
Masse (GND)
Signaux de contrôle
DMX+ (A)
DMX- (B)
⚠️ Points critiques :
  • NE PAS inverser DMX+ (A) et DMX- (B)
  • Pin A (7) = DMX+ = XLR Pin 3 = Vert
  • Pin B (6) = DMX- = XLR Pin 2 = Rouge
  • XLR Pin 1 = GND/Shield = Noir
  • DE et RE doivent être reliés ensemble à GPIO21
  • Résistances R5/R6 stabilisent la ligne au repos
  • Résistance de terminaison 120Ω : seulement sur le DERNIER appareil DMX

Table de connexions DMX OUT

ESP32 MAX485 XLR3 Fonction
GPIO17 Pin 1 (DI) - Données TX DMX
GPIO21 Pin 2+3 (DE/RE) - Enable TX/RX
GPIO16 Pin 4 (RO) - Données RX (optionnel)
+5V Pin 8 (VCC) - Alimentation
GND Pin 5 (GND) Pin 1 Masse commune
- Pin 7 (A) Pin 3 DMX+ (Signal différentiel +)
- Pin 6 (B) Pin 2 DMX- (Signal différentiel -)

3. Schéma complet intégré

📋 Récapitulatif des connexions principales :
  • MIDI IN : DIN5 → 6N138 (isolation) → ESP32 GPIO22
  • DMX OUT : ESP32 GPIO17 → MAX485 → XLR3
  • Alimentation : USB 5V → ESP32 + 6N138 + MAX485
  • WiFi : Point d'accès "MIDI-DMX-Interface" sur ESP32
